# Objetivos

Lista de objetivos:
- Control de multiples dispositivos
- Acceso remoto
  Despliegue en infraestructura publicamente accesible (VPS)

- Control de acceso
  Control de autorizacion y autenticacion

- Comunicacion segura
  Comunicacion encriptada

- Interoperabilidad multiplataforma
  Soporte de cliente Windows, GNU/Linux, Termux
  Soporte de servidor GNU/Linux

- Simplicidad y limites acotados
  Con una definicion de alcance y cobertura bien establecidos, que eviten un proyecto con arquitectura compuesta, capas, adaptadores, etc. que agranden la complejidad, complicacion, desarrollo o costo antes de ofrecer un producto funcional y usable.
